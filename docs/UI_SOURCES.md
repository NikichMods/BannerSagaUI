## Прямые отзывы игроков

Публичный Steam appreviews API, по одному запросу до 100 последних **отрицательных англоязычных** отзывов на каждую игру: `filter=recent`, `review_type=negative`, `purchase_type=all`, `num_per_page=100`. Это целевой поиск жалоб, не выборка для оценки частоты проблем или общего отношения игроков. Поиск по UI/interface/tooltip/inventory/font/menus пропускает иные формулировки и может находить пустые заголовки. Содержательные фрагменты ниже прочитаны вручную. Один автор или скопированный отзыв о трилогии не считаются независимыми голосами.

Сырые ответы оставлены в игнорируемой local/research-reviews. Первый запрос `filter=all` вернул лишь 2/1/3 записи и не использован как широкая выборка. Уточнённые запросы `filter=recent` вернули по 100; это по-прежнему не статистика распространённости. API URL воспроизводится как `https://store.steampowered.com/appreviews/<appid>?json=1&filter=recent&language=english&review_type=negative&purchase_type=all&num_per_page=100`.

## Как использовать противоречия

Понятность малых чисел и цветового кода может сочетаться с плохой обнаружимостью сведений и перегрузкой. Положительные E04 и отрицательные E06/E07/E08 описывают разные свойства. Разделять экран, устройство ввода, плотность ситуации и навык игрока; не усреднять их в «UI хороший/плохой». Отсутствие замечания в обзоре не доказывает отсутствие проблемы.
