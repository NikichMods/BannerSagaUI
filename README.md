# BannerSagaUI

Систематический аудит и обоснованные улучшения UI/UX The Banner Saga 1 (Steam, Windows), без ребаланса. Допускается существенная переработка экранов при сохранении художественного стиля; состав мода выводится из исследования проблем, а не из доступности первой правки.

**Начать с [карты проекта](docs/PROJECT.md):** цель, текущее положение, открытые вопросы, варианты и обоснование следующего шага. Проектные правила продолжения работы закреплены в AGENTS.md.

Текущий этап: предметный каталог кампании собран по EN/RU-источникам и отдельным статическим проверкам; выбираем главные цели до макетов. Первый технический цикл с одной русской строкой выполнен, но не определяет границы продукта. Приёмка UX и стабильный релиз остаются отдельными этапами.

Сборка: `python tools/build.py --game-root <каталог-tbs> --out <новый-каталог>`.
Тесты: `python -m unittest discover -s tests`.
Нужны собственная легальная установка игры и Python (проверен 3.12.14). Инструмент не скачивает и не распространяет игровые файлы. Выходной ресурс содержит материал Stoic и предназначен для локальной установки; в Git он не включается.
