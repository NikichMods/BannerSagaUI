# BannerSagaUI

Систематический аудит и обоснованные улучшения UI/UX The Banner Saga 1 (Steam, Windows), без ребаланса. Допускается существенная переработка экранов при сохранении художественного стиля; состав мода выводится из исследования проблем, а не из доступности первой правки.

**Начать с [карты проекта](docs/PROJECT.md):** цель, текущее положение, открытые вопросы, варианты и обоснование следующего шага. Проектные правила продолжения работы закреплены в AGENTS.md.

Текущий этап: первым направлением выбрана ясность боя. Подготовлена исследовательская правка стрелок «Тарана» по мышиному наведению; сборка и игровая проверка ведутся по [CANDIDATES.md](docs/CANDIDATES.md), точная идентичность — TEST_BUILD_LOG.md. Это первый ограниченный эксперимент, без полного прогноза конечных характеристик. Приёмка UX и стабильный релиз остаются отдельными этапами.

Исследовательская проба «Тарана»: `python tools/build_ram_hover.py --game-root <каталог-tbs> --java <java.exe> --ffdec <ffdec-cli.jar> --out <новый-каталог>`. Проверенные инструменты и границы — в инженерном справочнике.

Текущая диагностическая проба расчёта test.3: `python tools/research/build_ram_probe.py --game-root <проверенный-оригинал> --java <java.exe> --ffdec <ffdec-cli.jar> --out <новый-каталог> --freeze`. Числа пока только в локальном журнале; границы и пользовательский сценарий — [CANDIDATES.md](docs/CANDIDATES.md), точная идентичность/установка — [TEST_BUILD_LOG.md](docs/TEST_BUILD_LOG.md). Донорный SWF не устанавливать; DEV-вариант учитывается отдельно.

Сборщик первой текстовой пробы: `python tools/build.py --game-root <каталог-tbs> --out <новый-каталог>`; он не собирает изменение SWF.
Тесты: `python -m unittest discover -s tests`.
Нужны собственная легальная установка игры и Python (проверен 3.12.14). Инструмент не скачивает и не распространяет игровые файлы. Выходной ресурс содержит материал Stoic и предназначен для локальной установки; в Git он не включается.
