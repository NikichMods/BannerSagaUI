# BannerSagaUI

Исследование и небольшие обратимые улучшения понятности интерфейса The Banner Saga 1 (Steam, Windows), без ребаланса.

Текущий этап: первая русская текстовая проба. Подтверждены формат ресурсов и штатные потребители подсказок. Проверка в игре и приёмка — отдельные этапы; см. docs/CANDIDATES.md.

- [Проверенные данные и источники](docs/RESEARCH.md)
- [Аудит, приоритеты и реализуемость](docs/UI_AUDIT.md)
- [Тестирование и кандидаты](docs/CANDIDATES.md)

Сборка: `python tools/build.py --game-root <каталог-tbs> --out <новый-каталог>`.
Тесты: `python -m unittest discover -s tests`.
Нужны собственная легальная установка игры и Python 3.13. Инструмент не скачивает и не распространяет игровые файлы. Выходной ресурс содержит материал Stoic и предназначен для локальной установки; в Git он не включается.
